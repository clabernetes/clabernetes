Clabernetes, also known as **c9s** <span className='text-fd-muted-foreground text-sm'>(pronounced "see-nines")</span> allows you to run containerlab network topologies across a K8s cluster, achieving scalability, flexibility, and diverse deployment options.

While Containerlab is constrained by the resources of a single node (VM or bare metal), c9s creates a K8s deployment for each topology node, connects interfaces across them, and exposes management services through Kubernetes services API.

<IntroFabricDiagram />

C9s can be installed on any K8s cluster and **does not** require a custom CNI.

If you want to try c9s with a throw-away KinD cluster, follow the quickstart guide. If you want to install c9s into an existing cluster, follow the installation guide.
