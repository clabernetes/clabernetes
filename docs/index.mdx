Clabernetes, or **c9s** <span className='text-fd-muted-foreground text-sm'>(pronounced "see-nines")</span>, runs containerlab network topologies across a Kubernetes cluster.

A containerlab host is bounded by the resources of a single machine. c9s removes that bound: it runs each topology node in its own Kubernetes Deployment, wires the node interfaces together across Pods, and exposes management access through Kubernetes Services.

<IntroFabricDiagram />

c9s installs on any Kubernetes cluster and does not require a custom CNI.

To try c9s in a throw-away KinD cluster, follow the quickstart. To install c9s into an existing cluster, follow the installation guide.
